- Live Windows UI and theme switching were not exercised: the synthetic preview uses an existing
  settings directory without an override, so it was not launched into those settings. The packaged
  asset files match the reviewed inputs, and the theme-resource XAML compiled successfully.
- The iPad customizer's transient accessibility controls did not remain reliable enough for an
  additional installed dark-mode capture. The universal artwork's six appearances were checked on
  the installed iPhone and in Apple's renderer.
- Vision Pro Home View and headset parallax were not observed. The build and circular layer layout
  were checked; the current shared Device panel does not expose a Vision Pro target.
- No signing profiles, certificates, entitlements, release versions, or installed Mac/Windows apps
  were changed. This is a source integration and local verification, not a public release.

dark render when appropriate. Documentation renders are 512 px; the icon canvases and flat masters

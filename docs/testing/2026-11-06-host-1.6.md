# Casement Host 1.6 release

## Source and artifacts

Release source: `6a92d125d78cb325cea3553acc0b10b4cede23b9`, the end of the Curtain branch. PR #16 had been
squash-merged to main as `962c239` just before the bump, so the tag isn't an ancestor of main; compared
with `962c239` it adds only the version bump and two delivery documents. Mac version 1.6, build 5; Windows
version 1.6 for x64 and ARM64.

[Host 1.6](https://github.com/dlev02/Casement/releases/tag/host-1.6) was published as the latest stable
release with eleven assets. [Release log](../releases/host-1.6.md).

## Mac

`scripts/make-mac-release.sh 1.6` made a Release archive and Developer ID export. Apple accepted the app
(`a7b4cf1f-e22b-400a-86d9-8a0f418a4564`) and the DMG (`db2d8a94-6f35-4b3b-84fa-007512c5355b`), and tickets were
stapled and validated. `spctl` reports Notarized Developer
ID. Both the download and appcast Ed25519 signatures were checked with CryptoKit against the public key
in the shipping app. The Release binary started in `--curtain-guard` mode: it stayed up, listened on
nothing and left when stopped. Its lock path wasn't triggered.

## Windows

Built on the PC from the exact commit with `scripts/make-release.ps1 -Version 1.6`. Tests: 549 total, 545
passed, 0 failed, 4 opt-in skipped. Checksums, manifest URLs, hashes and sizes were checked on the PC and
again on the Mac. The manifest signature verifies against `ReleasePublicKeyHex` with the domain prefix, and
the signing key's public half matches it. Installers and the updater weren't run.

**ARM64 is probably broken, as in 1.5.** Its exe and runtime are arm64, but 44 native files, including
`Microsoft.ui.xaml.dll`, are x64, because `make-release.ps1` publishes both architectures with
`-p:Platform=x64`. It hasn't been run on ARM hardware. The release notes say so.

## Live endpoints

All eleven asset digests matched before publishing. Afterwards, anonymous `releases/latest/download`
requests for `appcast.xml`, `windows-update.json` and its signature returned files byte-identical to the
verified ones, and both Setup links and the versioned zips returned HTTP 200.

## Not proven

No installed copy has updated yet, and no real device has used Curtain against this release. Physical keys and
mouse being dropped, Control-Option-Command-L, Windows-L, the guard's lock path, click-through on Windows and
what the PC's panel shows are still unchecked. Artifacts and evidence: `~/Developer/Casement-Releases/host-1.6/`.

# Casement connects only over the person's tailnet

Casement and Casement Host talk only over Tailscale: the host's listener refuses any peer outside Tailscale's CGNAT and ULA ranges (loopback only in Debug builds), and there is no relay server, account system, LAN discovery or port forwarding. Tailscale already gives every device a stable address, encryption and access control, so Casement needs no servers of its own, collects nothing, and has nothing to keep running; pairing and Ed25519 keys on top prove which device and which computer are talking. The cost is that every user must set up Tailscale on both ends, and a computer at the login window before Tailscale starts (FileVault pre-boot) can't be reached. Supporting connections off the tailnet would mean a new security model, a privacy policy change and a server to run, so it needs Drew's decision first.

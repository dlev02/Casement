# The code keeps the Vantage names

The product was renamed Vantage → Porthole → Casement (2026-10-11, after a paid "Porthole: Remote Desktop" reached the App Store first), but only what a person sees and the bundle identifiers moved to the new name. Project, targets, modules, type names, the `vantage://` scheme, defaults keys, Keychain service names, log subsystems, debug flags and on-disk folders (`Application Support/Vantage Host`, `%LOCALAPPDATA%\Vantage Host`, the Windows Run value, DPAPI entropy, the firewall rule) keep Vantage, because renaming them would orphan existing installs' settings, trust stores and secrets, and a mass rename would touch nearly every file for no user-visible gain. New user-facing text says Casement; new code follows the surrounding Vantage names.
